# מדריך הפקת מסמכים לפי שיטת "חשבון עסקה"

דף נחיתה סטטי (HTML/CSS) עם הדרכה שלב-אחר-שלב להפקת חשבון עסקה ומסמך המשך, כולל תשלום חלקי, ביטול וניכוי מס במקור.

🔗 **צפייה באתר:** https://yehuda-menachem.github.io/paperless/

## קבצים
- `index.html` / `styles.css` – דף המדריך.
- `מדריך הפקת חשבון עסקה פייפרלס.pdf` / `.docx` – המדריך כקובץ להורדה.
